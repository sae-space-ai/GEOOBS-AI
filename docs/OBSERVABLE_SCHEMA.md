# Observable Schema — GEOOBS-AI

## Canonical Observable Record

Each geometric observable contains the following fields:

### Identification
| Field | Type | Description |
|-------|------|-------------|
| id | UUID v4 | Unique observable identifier |
| instrument | enum | MTG-FCI, METimage, GENERIC |
| platform | enum | MTG-I1, METOP-SG-A, SYNTHETIC, etc. |
| productLevel | enum | L1b, L1c, L2 |
| acquisitionTime | ISO 8601 | Observation timestamp |
| spectralBand | enum | FCI channel ID or COMPOSITE |

### Position
| Field | Type | Description |
|-------|------|-------------|
| pixelPosition | {row, col} | Position in image pixel coordinates |
| geoPosition | {lat, lon, crs} or null | Geographic position (null if not computable) |
| coordinateSystem | enum | pixel, geographic, projected |

### Feature
| Field | Type | Description |
|-------|------|-------------|
| featureId | UUID | Identifier of the detected feature |
| featureDescriptor | string | Hashed descriptor for traceability |

### Reference & Displacement
| Field | Type | Description |
|-------|------|-------------|
| referenceSystem | string | Description of reference used |
| expectedPosition | {row, col} | Position expected by reference |
| observedPosition | {row, col} | Position actually observed |
| displacement.dx_pixels | float | Horizontal displacement (pixels) |
| displacement.dy_pixels | float | Vertical displacement (pixels) |
| displacement.dx_geodetic_m | float or null | Horizontal displacement (meters) |
| displacement.dy_geodetic_m | float or null | Vertical displacement (meters) |
| displacement.magnitude_pixels | float | Total displacement magnitude (pixels) |
| displacement.direction_rad | float | Direction in radians |
| displacement.direction_deg | float | Direction in degrees [0, 360) |

### Quality & Uncertainty
| Field | Type | Description |
|-------|------|-------------|
| uncertainty.sigma_x_pixels | float | X uncertainty (pixels) |
| uncertainty.sigma_y_pixels | float | Y uncertainty (pixels) |
| uncertainty.confidence | float [0,1] | Detection confidence |
| uncertainty.source | string | Source of uncertainty estimate |
| qualityMetric | float [0,1] | Overall quality metric |

### Detection
| Field | Type | Description |
|-------|------|-------------|
| detectionMethod | enum | shi-tomasi, orb, sift, deep-feature |
| modelId | string or null | ML model identifier (null for classical) |
| modelVersion | string or null | ML model version |

### Conditions
| Field | Type | Description |
|-------|------|-------------|
| cloudCondition | enum | clear, partial, overcast, unknown |
| dayNightCondition | enum | day, night, twilight, unknown |

### Status
| Field | Type | Description |
|-------|------|-------------|
| status | enum | accepted, rejected, pending_validation, cloud_contaminated |

### Traceability
| Field | Type | Description |
|-------|------|-------------|
| sourceFileId | string | Source data file identifier |
| processingChainId | string | Processing chain identifier |
| createdAt | ISO 8601 | Creation timestamp |
| checksum | string | Integrity checksum |

## Conventions

1. **Pixel coordinates**: (row, col), origin top-left, row increases downward
2. **Displacement signs**: Positive dx = eastward/rightward, positive dy = southward/downward
3. **Geodetic displacements**: Computed only when valid geolocation parameters exist
4. **Never confuse** pixel coordinates with geographic coordinates
5. **Reference positions** generated by the same model being evaluated must be explicitly flagged

## Export Formats

- **JSON**: Full schema with all fields
- **CSV**: Tabular subset (position, displacement, quality, status)
- **NetCDF**: Planned (requires Python scientific service)
